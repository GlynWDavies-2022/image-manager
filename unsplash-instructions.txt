--------------------------------------------------------------------------
Base URL
--------------------------------------------------------------------------

https://api.unsplash.com/

--------------------------------------------------------------------------
Header
--------------------------------------------------------------------------

Authorization: Client-ID YOUR_ACCESS_KEY

--------------------------------------------------------------------------
Search
--------------------------------------------------------------------------

GET /search/photos

--------------------------------------------------------------------------
Parameters
--------------------------------------------------------------------------

query    (M)
page     (O) : Default 1
per_page (O) : Default 10
order_by (O) : Default relevant: Values latest, relevant

--------------------------------------------------------------------------
Example
--------------------------------------------------------------------------

GET https://api.unsplash.com/search/photos?query=oceans

Authorization: Client-ID abc123
